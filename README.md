# 💜 Amikom University Website

A university website project inspired by Universitas Amikom Yogyakarta, developed as a final project for the Web Programming Introduction course during the 2023/2024 academic year.

This project presents university information through a multi-page website with a purple-themed design, interactive navigation, slideshow, and informational sections.

## ✨ Features

- **Home Page** — Displays the university's introduction and an image slideshow.
- **Profile Page** — Presents information about the university and its history.
- **Scholarship Page** — Provides information about scholarship opportunities.
- **Admissions Page** — Introduces university admission information.
- **Academics Page** — Displays information about faculties and educational programs.
- **Contact Page** — Provides the university's contact information, address, and Google Maps location.
- **Interactive Navigation** — Makes it easier to navigate between website pages.
- **Hover Effects** — Adds visual feedback to navigation elements and cards.
- **Responsive Components** — Uses Bootstrap components to support a more adaptable layout.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
- Visual Studio Code

## 🎨 Design Concept

The website uses purple as its primary color to reflect creativity and the visual identity associated with Universitas Amikom Yogyakarta. Dark blue, white, and black complement the design to create a professional and readable interface.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code.

## 🎓 Project Background

This project was developed collaboratively as a university assignment by two students during the 2023/2024 academic year.

The project provided practical experience in building multi-page websites, implementing interactive elements, and organizing web content using HTML, CSS, JavaScript, and Bootstrap.
